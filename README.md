# The Tired Dark Lord: A 100-Word Villain Monologue

Mortimer has trained his apprentice for thirty-four years — and named the boy Mortimer, too. Now there are two Mortimers, the forms are confused, and the notes are wrong. He keeps them anyway.

## Run it

```sh
python3 main.py
```

Writes the 98-word monologue (528 characters, inside the 600-character gate) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or to `output/entry.txt` when the variable is unset. Pure Python standard library; no dependencies.
